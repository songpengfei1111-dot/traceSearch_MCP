# Large Text Searcher

专门用于处理大规模文本文件的高性能搜索与分析工具。支持高效的随机行访问、正则表达式搜索、加密算法魔数识别等功能，特别适用于日志分析、trace文件处理和大型数据文件的内容挖掘。

## 标准操作流程 (SOP

### 0. 准备阶段
- 阅读 trace_format 和 search_strategy 了解log格式和搜索策略

### 1. 文件探测与信息获取
- 使用 `file_info` 评估文件规模，制定合适的搜索策略
- 根据目标值（如 Hash 片段或寄存器值），使用 `search_text` 进行定位，从搜索结果中行数最小的位置向上寻找。
- 使用 `search_crypto_magic` 获知存在的加密算法

### 2. 内容定位与搜索
- **寄存器追溯**：若目标在 `(w) w0=0x123`，则向上搜索 `w0` 的写入点。
- **内存追溯**：若涉及 `(mr) 0x78de873000`（内存读取），立即搜索对应的 `st____ 0x78de873000`（内存写入）。
- **小端序处理**：搜索 4 字节数据失败时，尝试翻转字节序（如 `0x12345678` -> `78563412`）。

### 2.1 遇到可能的加密结果
- 当遇到很可能是加密算法的结果，需要按照下面的步骤操作
猜测加密类型 
if (is_hash加密):
  - 通过mcp-api获取魔数所在的行
  - 然找通过汇编指令stp，找到加密逻辑开始的位置
  - 然后获取context，阅读加密函数的入参
  - 使用python尝试计算加密的结果，看是否和目标值相符合
else:
  - 是否是base64，是的话尝试解码
    - 是否是标准base64
  - 是否是hash算法，有没有复杂的计算流程

### 3. 逻辑提取与模拟
- 识别 `eor` (异或), `add` (加法), `lsl` (逻辑左移) 等关键算术指令。
- 观察 `[libc.so::xxx]`, `[env::jni]` 等系统函数，利用 `dest` 和 `src` 地址跨段追踪数据。
- 提取关键常量或 S 盒数据，编写 Python 脚本尝试复现该段逻辑。

### 4. 收敛与总结
- 当追踪到原始明文输入、系统时间（`clock_gettime`）或随机数种子时，停止回溯。
- 整理完整的算法流程图，并提供验证通过的 Python 代码。

## 搜索策略约束
- **结果降噪**：若搜索结果超过 50 条，必须增加指令特征（如 `eor w8`）或缩小地址范围进行二次过滤。
- **透明化思考**：每一步搜索前需陈述搜索目的。

### 常见搜索模式
- **十六进制值搜索**：`pattern="0x[0-9a-fA-F]+"`（需启用regex）
- **函数调用搜索**：`pattern="function_name"`
- **内存地址搜索**：`pattern="0x[0-9a-fA-F]{8,16}"`（需启用regex）
- **指令搜索**：`pattern="mov|add|sub"`（需启用regex）
