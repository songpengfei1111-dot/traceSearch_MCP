你将要阅读一个 汇编指令的trace文件，下面是一些基本的片段和其格式的解释

# 最基本的汇编指令
78eb6a4d90 [92d90]	and w10, w10, #0xffffff00		 (r) w10=0xbd  (w) w10=0x0 

在这一句中 
78eb6a4d90 代表实际地址，一些内存读写的地址基于实际地址
[92d90] 是so内部相对地址，用来指示在ida中的位置
and w10, w10, #0xffffff00 是基本汇编指令
(r) w10=0xbd  (w) w10=0x0 代表寄存器读写状态


# 内存访问指令
78eb6a4d3c [92d3c]	str w9, [x19, #0x220]		 (r) w9=0x1d7 (mw) 78de873200
st____ 78de873420 4 1d7
78eb6a4d40 [92d40]	ldr w9, [x19, #0x224]		 (mr) 78de873200  (w) w9=0xb0 
ld____ 78de873424 4 b0

在这里(mw)和(mr)分别对应 x19，即内存访问的基地址，由于内存访问偏移#0x220为立即数imm，这里不打印
有时也会出现 (mr) 78de8730d0 +0x49 这种格式，在这种格式下可能是对 78de8730d0 附近的区域进行密集操作，可以关注一定范围内带有(mr) 78de8730d0的搜索结果
在内存访问语句下会有 st____/ld____ mem_access_addr mem_size rw_value 的内存访问提示

当出现: st____ 7c4775ad4c 时，代表这里存入的是0，通常上一行是wzr

# 寄存器指向可视化
如果一个寄存器指向的字符是可读的，那么会打印String__
比如，在这里 78eb784a70 指向一个可读字符 5256

但String提供的信息只供参考，
比如String__ 78de8731e0—>J 不能提供任何有用信息
